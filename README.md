# Basic Data Tools

This project contains basic command-line tools for transforming, parsing, and summarizing data.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # On Windows, use .venv\Scripts\activate
python -m pip install -r requirements.txt
```

## Test

```bash
python -m pytest
```
